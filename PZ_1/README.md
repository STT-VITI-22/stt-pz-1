#  JavaScript Function Library with Tests

Цей проєкт містить набір JavaScript-функцій та автоматизованих тестів, створених для демонстрації базових математичних і утилітарних операцій. Тестування реалізовано з використанням **Mocha** та **Chai**.

---

## Реалізовані функції (`lib.js`)

| Назва функції       | Опис                                                                 |
|---------------------|----------------------------------------------------------------------|
| `sum(a, b)`         | Додає два числа або рядки, які конвертуються в числа.               |
| `pow(x, n)`         | Підносить число `x` до степеня `n`.                                 |
| `factorial(n)`      | Обчислює факторіал числа `n`.                                       |
| `fibonacci(n)`      | Обчислює `n`-е число Фібоначчі.                                     |
| `removeByName(list, name)` | Видаляє обʼєкт з масиву за полем `name`.                           |
| `makeCounter(start)`| Повертає функцію-лічильник, яка інкрементує значення.              |
| `getAsyncTimerId(time)` | Повертає Unix-час після тайм-ауту (логічна заглушка).              |
| `asyncMultiply(x)`  | Асинхронно множить число `x` на 2 через `Promise`.                  |
| `httpGet(url)`      | Виконує HTTP GET-запит через `XMLHttpRequest`.                      |

---

##  Автоматичне тестування (`lib.spec.js`)

Тести реалізовано з використанням:

-  **Mocha** — фреймворк для тестування
-  **Chai** — бібліотека для асерцій

### Протестовані функції:

-  `sum` — перевірка чисел, рядків, відсутнього аргументу
-  `pow` — перевірка піднесення до степеня
-  `removeByName` — перевірка видалення об'єкта по імені

### Результат:

✔ Усі тести проходять успішно після виправлення функції `removeByName`.

---

##  Як запустити тести

1. Відкрий файл `index.spec.html` у браузері.
2. На сторінці зʼявиться інтерфейс Mocha з результатами.
3. Переконайся, що всі скрипти (`lib.js`, `lib.spec.js`) доступні у папці `./js/`.
